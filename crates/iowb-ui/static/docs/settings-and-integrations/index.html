Settings and integrations

Settings is the operator desk for the workbench's rich control surfaces: provider readiness, Git identity, access material, browser notifications, optional IO Gateway chat, runtime health, and command-backed tools. Use it to make a deliberate host configuration visible—not to grant a browser or phone new authority by accident.

A safe configuration sequence

  1. 1
    Confirm the host boundary

    Select the intended project and confirm the server URL, authenticated account, workspace root, and remote-access boundary before editing credentials or running tools.

  2. 2
    Prove the small control

    Use CLI Status, Git Config, Load Notifications, or Server Status to inspect current state before saving a change.

  3. 3
    Save one scoped change

    For tokens, notifications, or an IO Gateway connection, change one field set at a time and keep secrets out of chat transcripts, screenshots, and mobile/browser source.

  4. 4
    Test without broad execution

    Use Preview for notifications, a small agent task for a CLI/gateway change, and a harmless command/path for a command-backed integration.

  5. 5
    Review the result

    Check Server Status, tool-run history, session output, Git evidence, and the remote client boundary before treating the configuration as ready.

Command-backed tools are host execution

The Tools tab can start/list/stop configured MCP servers, run MCP/utility/command/plugin/Taskmaster/notification actions, and send audio to a configured transcription command. These are deliberately command-backed integrations, not managed SaaS switches.

  • Use explicit paths and arguments; do not paste unreviewed commands into a host-control form.
  • Keep environment and workspace scope narrow; an integration inherits authority from the server host.
  • Test the least-impacting action first and inspect persisted tool output before enabling a broader workflow.
  • Disable or remove stale integrations when their command, credential, or access boundary is no longer intended.
