io-workbench has separate keyboard maps for the desktop Web workspace and the mobile Android / web harness / PWA clients. The mobile PWA follows the mobile map, not the desktop browser map. Use a physical keyboard for mobile shortcuts.

Read the notation

NotationMeaning
Ctrl/CmdUse Ctrl on Windows/Linux or Cmd on macOS. A mobile keyboard that sends the Meta/Command modifier follows the same command-style bindings.
+Hold the modifier while pressing the following key. For example, Ctrl/Cmd+. means Ctrl or Command plus period.
↑, ↓, ←, →Arrow keys. A mapping is contextual when its table says a prompt, editor, grip, board tabs, or Home is focused.
EscDismisses the current app-owned overlay or modal when that surface offers an Escape action. Browser and operating-system reserved shortcuts can still take precedence.

Chat Escape behavior

Esc first closes or cancels the active Chat transient state, such as a staged edit or running response. With a blank persisted prompt, use the offered second Escape action to open Edit from here.

Web workspace — desktop browser

These are browser-workspace behaviors. They apply to the full desktop Web workspace, not to the mobile web harness/PWA.

ShortcutContextDesktop Web behavior
Enter / EscInline file or folder nameCreate/rename the item / cancel the inline edit.
EscDocs searchClear and blur the search field.
Tab / Shift+TabGit or Board modalKeep focus inside the open dialog; Esc closes it.
Printable keys, Ctrl+letter, and terminal navigation keysShellSend input to the server-hosted PTY. Enter, Backspace, Tab, Esc, arrows, Delete, Home, End, Page Up, and Page Down are forwarded; Alt/Meta are not sent by the Web Shell key handler.
Mobile-only controls are absent

The desktop Web workspace does not bind Alt+P, Alt+M, unfocused-Chat arrow scrolling, Home-card arrows, or Board-column arrow navigation.

Mobile apps — Android and web harness/PWA

The Android app and mobile web harness/PWA share the following hardware-keyboard contract. The PWA is intentionally listed here because it is a mobile client, even though it runs in a browser.

ShortcutContextMobile behavior
Alt+PChat, editable Files, or GitFocus or unfocus the primary text input: the Chat prompt, active editable file, or Git commit message. Alt+I is no longer a shortcut.
Alt+MAnywhere outside a blocking dialogOpen Home/More and focus its navigation.
↑ / ↓Chat with no text input focusedScroll the transcript. Use Shift+↑ / Shift+↓ for a larger, faster scroll.
EnterFiles → Go to lineMove the editor cursor to the requested line.
↑ / ↓Home/MoreFocus the previous/next project or session card. At either edge, the card remains focused; arrows do not fall through to page scrolling.
← / →Home/MoreMove focus between the Home navigation controls without activating them.
← / →, Home / EndFocused Board column tabsFocus the previous/next column, or the first/last column.
Terminal keysRemote terminalUse terminal semantics for host-PTY input. Android forwards standard control/navigation keys; the PWA uses the xterm terminal's native mappings.
Reorder grips win over Home navigation

When a project or pinned-session reorder grip has focus, its ↑/↓ reorder action takes precedence over Home-card navigation.

Android native Database workspace

These controls are native-Android-only. The mobile web harness/PWA does not currently expose the Database workspace.

ShortcutAndroid Database action

Ctrl/Cmd+RRefresh the current table, or run the current SQL query.
Ctrl/Cmd+WClose the active Database panel.

Ctrl/Cmd+SpaceOpen SQL autocomplete. Use ↑/↓ to choose, Tab or D-pad center to accept, and Esc to dismiss.

When a shortcut does not work

  • Check focus first: prompt, editor, search, drag grip, board tabs, Home, and terminal mappings apply only to their active control.
  • Use a physical keyboard on mobile: touch controls remain available, but they do not synthesize the hardware-keyboard shortcuts.
  • Expect native/browser reservations: the browser, operating system, keyboard firmware, or an accessibility service can reserve a key combination before io-workbench receives it.
  • Keep the surface straight: use this page's Web table for the desktop browser workspace and its Mobile table for Android or the mobile PWA.
