Get started

Quick startInstall a released host or source build, create the first account, and prove a local workspace is ready.Install and updateInstall checked release builds on Linux, macOS, Windows, or Android and update them without starting an unintended service.Web workspaceUse the browser UI from first sign-in through a reviewable agent, code, Git, data, and terminal loop.Mobile appsInstall the released Android client or build it from source, use the mobile web/PWA route, and connect it safely to a running host.Native desktop clientBuild and use the source-built wxWidgets desktop client to control a local or remote io-workbench host.Remote accessReach an io-workbench host from another browser or phone without exposing a development listener carelessly.

Workbench workflows

Agents and sessionsRun configured Claude, Codex, and Gemini CLIs with durable project sessions and reconnect-aware history.Projects, files, and GitKeep host directories, file edits, diffs, branches, and remote Git operations in one reviewable project context.Database workspaceSave connections, inspect schemas, run SQL, work with paginated data, and understand browser versus Android clipboard capabilities.Terminal and mobile controlsOperate a live server-hosted PTY from the browser or Android without mistaking it for a local device shell.

Operate safely
