Field system 01 / self-hosted development

Run the real machine.
Not another chat tab.

io-workbench replaces a single-agent remote workflow with the working environment around it: your configured Claude, Codex, and Gemini CLIs; the codebase; Git; databases; a live terminal; and the proof needed to ship. The host stays yours. The control surface travels.

Operating model / not a chat mirror

One remote login. The evidence stays attached.

SSH gets you into a machine. io-workbench keeps the host, agents, data, shell, Git, and validation in the same working frame—whether you open it from a laptop, desktop launcher, or phone.

  1. 01

    Connect to your host

    Your server runs the CLIs, workspace processes, and PTY. You keep the control plane in the browser.

  2. 02

    Bring the right agent

    Choose Claude, Codex, or Gemini per task and preserve the project context around every session.

  3. 03

    Ground the work in evidence

    Inspect rows, terminal output, files, Git changes, and validation before it moves forward.

One remote desk. Three agents.

Pick Claude, Codex, or Gemini—never a smaller workspace.

Choose the provider that fits the moment, then keep its work anchored to the same project, files, Git state, host, and decisions. It is the freedom of a multi-agent bench without the context tax.

  • Launch or resume configured Claude, Codex, and Gemini CLI sessions
  • Project-scoped history, model settings, files, and working context
  • Live streaming with reconnect and session recovery when the browser drops

Navicat instincts, inside the project

Data work that stays beside the code changing it.

Connect real databases, trace relationships, run SQL, inspect rows, and move data without leaving the remote workspace. Your agent can reason over the same schema and evidence you are looking at—not a screenshot in another tab.

  • Saved SQLite, PostgreSQL, MySQL, and MariaDB connections
  • Schema explorer, relationship views, SQL editor, paginated data, and SQLite table transfers
  • Native Android data grid can select rows and copy or paste structured JSON/CSV

The shell stays yours

A real remote terminal—not an output pane.

Open a server-hosted PTY from the web or Android and work like you are at the machine. Type, resize, paste, follow live output, and control the process while your workload stays safely where the code lives.

  • Interactive PTY input/output, resize, restart, abort, and process controls
  • Clipboard copy and paste for the commands and evidence you need
  • Android native terminal renderer powered by Termux components, with Esc, Tab, Ctrl, Alt, and arrows

The outcome layer

Make agent work visible, reviewable, and shippable.

Turn a broad request into scoped work with a clear route to done. Use the Agentic Board to approve the plan, see what is running, add validation, and keep Git evidence attached before anything ships.

  • Backlog, task hierarchy, providers, policies, and approval boundaries
  • Validation, QA, retries, and follow-up work in the delivery flow
  • Project, Git, agent, and host context stay connected from plan to proof

Run it where your code lives

Your host does the work. Your browser becomes the cockpit.

Run io-workbench beside the repositories, databases, and provider CLIs you already trust. The host owns the code, processes, and PTY; your laptop or phone gets the control surface wherever you are.

● Authentication is enabled by default. For remote access, use your own VPN, reverse proxy, or authenticated tunnel; provider CLIs must be installed and configured on the server.
