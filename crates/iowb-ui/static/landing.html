The self-hosted remote command center

Beyond Claude Remote.
Your whole dev machine,
from anywhere.

io-workbench is built to replace a single-agent remote workflow with the complete desk: run your configured Claude, Codex, and Gemini CLIs beside the codebase, Git, databases, a live terminal, and the delivery plan they need. Securely expose that host through your own VPN, reverse proxy, or tunnel—and carry the desk with you.

A remote coding tool should do more than mirror chat

One remote login. Every surface the work touches.

SSH is not a workspace. io-workbench keeps the host, agents, data, shell, Git, and evidence connected—whether you open it from a laptop, desktop launcher, or phone.

  3. 03

    Ground the work in evidence

The shell stays yours

A real remote terminal—not an output pane.

Open a server-hosted PTY from the web or Android and work like you are at the machine. Type, resize, paste, follow live output, and control the process while your workload stays safely where the code lives.

  • Interactive PTY input/output, resize, restart, abort, and process controls
  • Clipboard copy and paste for the commands and evidence you need
  • Android native terminal renderer powered by Termux components, with Esc, Tab, Ctrl, Alt, and arrows

Run it where your code lives

Your host does the work. Your browser becomes the cockpit.

Run io-workbench beside the repositories, databases, and provider CLIs you already trust. The host owns the code, processes, and PTY; your laptop or phone gets the control surface wherever you are.

● Authentication is enabled by default. For remote access, use your own VPN, reverse proxy, or authenticated tunnel; provider CLIs must be installed and configured on the server.
