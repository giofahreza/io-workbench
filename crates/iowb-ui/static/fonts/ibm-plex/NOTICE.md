# IBM Plex webfont assets

The files in this directory are unmodified WOFF2 subsets from IBM Plex:

- IBM Plex Sans 1.1.0
- IBM Plex Mono 2.5.0
- IBM Plex Sans Condensed 2.0.0

They are self-hosted so the public landing page does not make a third-party
font request. The bundled files are licensed under the SIL Open Font License
1.1; see `LICENSE.txt` in this directory for the complete license text.

Source: https://github.com/IBM/plex
